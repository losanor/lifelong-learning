# Release Decision — MVP Sujo Tarefas

Status: Aprovado para experimento com usuários

Data:
Fluxo executado:
Discovery → Product → QA Planning → Engineering Lead → Implementation Operator → Claude Code → QA Execution

Decisão:
O MVP Sujo está aprovado para exposição controlada a usuários reais como experimento de aprendizado.

Não está aprovado para Engineering completa.

Ressalvas:
- Ajuste opcional na geração de ID com sufixo aleatório.
- Revisar eventual inconsistência de nomenclatura de chaves no localStorage, garantindo uso de tasks e analytics.

Próximo passo:
Testar com 5 usuários por 3 a 5 dias.

Critérios mínimos de aprendizado:
- Usuário consegue criar tarefa sem instrução.
- Usuário consegue marcar/desmarcar tarefa.
- Usuário retorna em pelo menos 2 dias distintos.
- Usuário não pede imediatamente features complexas como datas, categorias, recorrência ou sincronização.
